# M.Tech Compass

A static, mobile-first KTU M.Tech CSE syllabus navigator. It provides course and module navigation, topic search, curated resource links, browser-local progress tracking, and saved courses.

## Deploying with GitHub Pages

This repository is ready to publish directly from the `main` branch. In the GitHub repository, open **Settings → Pages**, select **Deploy from a branch**, then choose `main` and the `/(root)` folder.

The app needs the tracked file at `prep/mtech_cse_ktu_2026_resource_registry.json`. The source PDF and working reports are intentionally excluded from Git so they are never published.
